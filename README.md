# Testes Manuais - Extensão em Qualidade de Software

Repositório de estudo, prática e documentação de testes manuais de software, desenvolvido na disciplina de Extensão - Qualidade de Software (UniALFA, Sistemas para Internet).

## Objetivo
- Praticar QA e organização de casos de teste
- Simular testes em sistemas reais
- Montar um portfólio técnico para oportunidades profissionais

## Estrutura
- **SIFIT**: análise de requisitos, plano de testes, cenários, relatório de bugs e relatório dos testes
  - `1-Analise-de-requisitos.md` — 46 requisitos funcionais (RF01–RF46)
  - `2-plano-de-testes.md`
  - `Cenarios-de-testes/` — um arquivo por requisito (`CT_RFxx_...`), casos em Gherkin (DADO/QUANDO/ENTÃO)
  - `3-Relatorio-de-Bugs.md` — 21 bugs
  - `4-Relatorio-dos-testes.md` — 108 casos, resultado por módulo e por caso
  - `evidencias/imagens/` — capturas de tela
  - `anexos/` — matriz de rastreabilidade, investigações, consolidação da equipe, análise dos vídeos, conferência do banco e inventário de telas

## Metodologia
Testes positivos, negativos e exploratórios, com evidências em vídeo (Jam) e print, e conferência de dados no banco por consultas de leitura.

## Ferramentas
Jam (gravação de evidências), MySQL Workbench, DevTools do navegador, Markdown e GitHub.
